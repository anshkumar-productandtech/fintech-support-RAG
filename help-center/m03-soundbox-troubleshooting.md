# Soundbox isn't announcing payments

First check the payment in the **Kuberix for Business** app. If it shows there, the payment is safe; only the announcement failed.

## Quick fixes

1. **Is it on and charged?** The light should be green. Red means low battery: charge it with the cable supplied.
2. **Is the volume up?** Press **+** a few times.
3. **Does it have network?** The network light should be blinking blue. If it's off, move the Soundbox near a window or door and restart it.
4. **Restart it:** hold the power button for 10 seconds until it turns off, then turn it on again.

## Light colours

| Light | Meaning |
| --- | --- |
| Solid green | On and ready |
| Blinking blue | Connected to network |
| Solid red | Battery below 10% |
| Blinking red | No network |
| No light | Off, or battery empty |

## Still not working?

Raise a ticket from **Help > Soundbox issue**. If it can't be fixed by phone, we replace it free within 3 working days. Replacements due to physical damage cost ₹999.
